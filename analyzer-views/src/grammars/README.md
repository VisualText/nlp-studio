# NLP++ TextMate grammars

A copy of `syntaxes/` from [VisualText/nlpplus-tmbundle](https://github.com/VisualText/nlpplus-tmbundle)
at `ab5328e`, under its MIT license (`LICENSE`, beside this file). These are the grammars the NLP++
VS Code extension uses. Shiki tokenizes with them (`../highlight.ts`), for `<nlp-code>` and for
NLP Studio's Monaco editor.
